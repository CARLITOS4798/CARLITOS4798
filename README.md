# Nuestra Tienda

Tienda virtual que reúne cuatro emprendimientos familiares:

- **Apetitivos Dios Proveerá**: sándwiches, jugos naturales y chicha de arroz.
- **Perfumes y Cremas**: productos por catálogo de Natura, Ésika y Yanbal.
- **Variedades Jehová Nisi**: productos de aseo.
- **Venta de Hielo**.

👉 Página publicada: https://carlitos4798.github.io/CARLITOS4798/

## Cómo editar el contenido

Todos los negocios y productos están en [`src/data/negocios.js`](src/data/negocios.js).
Las fotos van en `public/imagenes/`. Cada vez que se suben cambios a `main`,
la página se publica sola (ver `.github/workflows/publicar.yml`).

## Trabajar en el computador

```bash
npm install
npm run dev
```
